`Packages/`, `ProjectSettings/` and everything under `Assets/` except `Assets/Simulacra/` were copied
from XREAL's template project (https://github.com/dengxian-xreal/XREALSDKTemplate, Unity 2022.3.62f2,
XREAL SDK 3.1.0, AR Foundation 5.2.0, XR Interaction Toolkit 2.6.5) so the project opens already
configured for XREAL glasses. That includes XREAL's and Unity's imported sample assets under
`Assets/Samples/`, which remain under their own licences. The XREAL SDK itself is not in this
repository; `get-xreal-sdk.sh` downloads it from XREAL.
